# v0.2 连接修复版

本版将 LAN 连接改为 RsInstrument 官方 SocketIo 后端，避免依赖系统 VISA / PyVISA VXI-11 后端。
输入仪器 IP 即可，旧 TCPIP::IP::INSTR 地址也会转换为同一设备的 TCP 5025 连接。
“网络诊断”只连接该地址并查询 *IDN?；不扫描局域网、不修改网络配置。
支持保存无测量数据时的错误日志。端口不可达时，软件无法替代网络配置修复。
固件目标为 ESR 3.66，仍需真实 ESR3 联调。原有测试限制如下。

# ESR3 CE 工作台 v0.1

Windows 桌面工程联调版，中文界面。**EXE 可直接双击运行，无需安装 Python。未连接真实 ESR3 验证，不作为正式符合性判定工具。**

## 已实现

- 模拟演示；ESR3 VISA 连接检测（检测连接不预置、不启动测量）。
- 150 kHz～30 MHz，CISPR 6 dB / 9 kHz，固定频率逐点测量。
- PK / QP / CISPR Average，每次选择一个检波器；L/N 手动切换并记录。
- 起止频率相同可做单点复测；可修改驻留时间和步长。
- 曲线、最高五个读数、外部总修正、用户限值、数值裕量。
- 导出 CSV（Excel 可打开）、JSON 配置/状态、SCPI 通信日志；模拟数据带明确标记。
- 停止/异常保留部分数据，导出记录其状态；不静默跳过错误点。

## 在 Windows 上运行

需要 Python 3.11 或更新版本（建议 3.11），安装时包含 Tcl/Tk 与 Python Launcher。

1. 完整解压。
2. 仅演示：双击 `run_demo.bat`，不需安装第三方依赖。
3. 接收机连接：双击 `setup_and_run.bat`，首次联网安装依赖；选“ESR3 实机”。
4. 填写 ESR3 的 VISA 资源地址，点击“检测连接”。例：`TCPIP::192.168.1.100::INSTR`。电脑与仪器须网络可达。优先使用已安装的 R&S VISA；也带有 pyvisa-py 后端依赖，实际接口需联调。
5. 首次实机联调请把起止频率均设为 `1` MHz，只采一个点，与面板同设置读数对照；再尝试小频段，最后全频段。
6. 全带宽默认步长 4.5 kHz、约 6635 点。逐点 LAN 调用速度较慢，耗时大于“点数×驻留时间”。本版没有使用 FFT/TD Scan。
7. QP/CISPR Average 的驻留时间需要按具体测试方法及 EUT 信号周期设置。默认 20 ms 用于 PK 联调演示，不代表最终测量时间。

## 开始实测会改变什么

开始实测前会弹窗说明：执行 `*RST` 预置，选择 Receiver 模式、RF INPUT1、AC 耦合、50Ω、自动衰减、输入衰减保护开启、前放关闭；软件不自动恢复原有设置，请先在仪器自行保存。

只选择单个检波器，设置并回读带宽/滤波器/单位/驻留时间等；回读不匹配或返回多检波器结果会中止。每点设置频率、回读频率、启动单次 bargraph 测量、等待 OPC 完成，再读取 `TRAC? SINGLE`。

停止在当前点通信结束后生效，最长可能约驻留时间加通信超时。采集进行中不要从面板或其他软件更改仪器设置。

**尚未实现自动过载/欠量程判定、测量不确定度、正式标准配置与报告、原生快速预扫、自动峰值筛选复测、LISN 远控。** 实机数据须人工检查仪器状态；本版不出 PASS/FAIL。数值裕量只等于“用户限值－修正后读数”。

## 修正与限值 CSV

修正 CSV 表头：`frequency_hz,correction_db`。

外部总修正 = LISN 系数 + 线缆损耗 + 外部衰减器修正等（按实际链路及校准资料计算）。程序对接收机读数加该总修正。不要再次添加接收机内部自动衰减值。不能把其他 LISN 的固定系数套用到自己的仪器。

限值 CSV 表头：`frequency_hz,limit_dbuv`。请根据实际标准、版本、设备分组/等级、检波器、端口填写；软件不会替你核定适用性，PK 不能直接当成 QP/AVG 结论。

每个 CSV 至少两行数据，频率为 Hz 且严格递增，数据必须为有限数值，必须覆盖整个测量频段。频率按对数插值，禁止外推。第一版不支持同频率处不连续限值（重复频率会报错）；需按频段分开测量。

`examples/DEMO_ONLY_*` 是 0 dB 修正和恒定 60 dBµV **虚构演示数据**，不是任何标准或 LISN 校准文件。程序不会自动加载。

导出 JSON 保留测量时的完整曲线数据与配置快照，之后在界面加载新 CSV 不改变已有结果。

## 生成双击 EXE

方式 A：在 Windows 上双击 `build_windows.bat`；成功后为 `dist/ESR3_CE.exe`。打包需要 Python 和网络；目标电脑运行 EXE 不需要另装 Python，实机通信可能仍需 VISA 驱动。未做 Windows 10 实际运行验证。

方式 B：将本目录内容放到一个 GitHub 仓库根目录（保留 `.github`），在 Actions 手动运行 **Build Windows EXE**，完成后下载 `ESR3_CE_Windows` 产物。此工作流只生成构建产物，不发布 Release，也不进行仪器测试。本交付未上传仓库或执行云构建。
